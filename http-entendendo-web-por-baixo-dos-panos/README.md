# HTTP: Entendendo a Web por Baixo dos Panos #

[Curso na Alura](https://cursos.alura.com.br/course/http-entendendo-web-por-baixo-dos-panos)

Este curso é um pré-requisito do curso [NGINX: servidor Web, Proxy Reverso e API Gateway](https://cursos.alura.com.br/course/nginx-servidor-web-proxy-reverso-api-gateway)

## Preparando o Ambiente ##

### baixa backend
git clone https://github.com/alura-cursos/api-alurabooks.git
cd api-alurabooks
npm install
npm run start-auth

### baixa frontend
git clone https://github.com/alura-cursos/curso-react-alurabooks.git
cd curso-react-alurabooks
git checkout aula-5
npm install
npm start
